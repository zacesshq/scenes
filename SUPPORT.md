# Support

## Getting help

- **Questions and ideas:** start a thread in [Discussions](https://github.com/orgs/zacesshq/discussions).
- **A scene draws wrongly or the terminal is left in a bad state:** open an issue with the
  [bug report form](https://github.com/zacesshq/scenes/issues/new?template=bug_report.yml).
- **A new scene:** use the
  [scene idea form](https://github.com/zacesshq/scenes/issues/new?template=scene_idea.yml).
- **Something is hard to see, moves too much or flashes:** use the
  [accessibility problem form](https://github.com/zacesshq/scenes/issues/new?template=accessibility_problem.yml).
  An accessibility problem is a bug. You never need to share a diagnosis or anything personal. To
  report privately, email [contact@zacess.com](mailto:contact@zacess.com).
- **Security vulnerabilities:** never open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Anything else:** email [contact@zacess.com](mailto:contact@zacess.com).

## Self-help

- [README.md](README.md) for the scenes, the install steps, the keys, the flags and how the theme is
  picked
- [docs/scenes.md](docs/scenes.md) for what each scene draws and what it does under reduced motion
- [ACCESSIBILITY.md](ACCESSIBILITY.md) for the measured limits and the known gaps
- `zacess-scenes --help` for the flags and `zacess-scenes --list-themes` to see which theme would be
  used

> [!NOTE]
> If the terminal ever looks wrong after the program ends, `reset` in the shell puts it right. That
> should never be needed; if it was, please report it as a bug.
